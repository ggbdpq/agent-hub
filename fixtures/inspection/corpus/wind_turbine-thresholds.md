# 风力发电机组异常判据与告警阈值

> 合成数据文档：仅供 agent-hub 巡检多智能体离线评测与演示使用，非任何真实企业规程。

适用对象：风力发电机组（沿海风电场）
适用场景：安装验收、日常巡检、异常处置与维护作业。

## 正常运行范围

| 参数 | 正常范围 | 备注 |
|---|---|---|
| output_kw | 800~1500 | - |
| nacelle_temp_c | 30~60 | - |
| vibration_mm_s | 1.5~3.5 | - |
| rotor_rpm | 10~18 | - |

## 告警阈值

| 参数 | 阈值 | 动作 |
|---|---|---|
| vibration_mm_s | > 7.1 | 立即上报并启动异常处理流程 |

## 判读方法
- 单点越限：复核采样有效性，排除通信误码。
- 趋势越限：连续 3 个采样点单调偏离正常范围，判定为漂移类异常。
- 阶跃越限：相邻采样点变化幅度超过正常波动 3 倍，判定为突变类异常。

## 上报要求
判定异常后生成工单，注明设备编号、异常参数、实测值与判定依据。

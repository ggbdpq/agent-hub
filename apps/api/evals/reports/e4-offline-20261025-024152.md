## 方法

- 两臂共用同一 FanoutSimRunner 容器（E3 同款：真实 make_plan + 真实 run_inspection + 真实 ToolExecutor，asyncio.gather 并行镜像生产 Send 扇出）；容器未含 reporter 阶段（两臂相同常数项，不进入对照）。
- brief 臂 = 生产现状：B6 收敛简报（设备静态信息 + checks≤6 + 遥测摘要≤12 指标）；full_history 臂 = 完整遥测采样序列（全部点位）+ 全站设备清单 + checks 不截断。
- 指标复用 C8 run_case/aggregate；Token 为替身工厂估算口径（estimate_tokens）；时延为 run_case 墙钟（替身即时回复，不含真实推理）。
- 合规替身按工具回执决策、不读上下文载荷内容——两臂质量指标应一致，差异应全部落在输入 Token；若质量指标出现差异即为实现缺陷（本报告同时核对）。

## 已知偏差

- 离线口径：成功率与 P/R 验证的是评测流程与契约管道，不代表模型效果。
- 合规替身按 receipts 决策，不模拟「上下文变大导致注意力衰减/偏离」——真实模型下完整历史除计费差外还可能改变行为质量（方向不定，需真实模型重跑验证）。
- 容器未含 reporter 阶段（两臂相同常数项）；生产图完整口径的真实模型费用见估算节。
- Token 为脚本估算（estimate_tokens：CJK 0.7 token/字，其余 4 字符 1 token），非计费口径；真实模型的简报/历史 Token 占比与此估算可能有差异。
- full_history 臂的全站清单对应 R3 上下文隔离被打破的形态（站点级数据进子任务上下文），仅用于 Token 对照，不涉及越权执行（工具权限面两臂相同）。
